# Projeto Novo Futuro

Projeto acadêmico de Front-End desenvolvido com HTML5 semântico.

## Estrutura
- `index.html` — apresentação da ONG e contato.
- `projetos.html` — projetos, doações e voluntariado.
- `cadastro.html` — formulário de cadastro.
- `imagens/` — logo e imagens em PNG, JPG e WebP.
- `scripts/mascaras.js` — máscaras de CPF, telefone e CEP.

## Recursos de HTML5
- Estrutura semântica: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Hierarquia de títulos: `h1`, `h2` e `h3`.
- Formulário com `fieldset` e `legend`.
- Validações nativas: `required`, `type="email"`, `type="date"`, `pattern`, `min`, `max` e `minlength`.
- Acessibilidade: `lang`, `label`, `alt`, `aria-label` e `aria-labelledby`.

## Observação
As imagens são ilustrativas e foram criadas para este projeto acadêmico. Os dados institucionais são fictícios e podem ser substituídos pelos dados fornecidos pela faculdade.

A validação do W3C deve ser realizada após a edição final dos arquivos, usando o HTML Validator oficial.
